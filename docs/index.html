Two-Tower Mathematical Architecture

Decoupled Dual Neural Projections & Candidate Retrieval

1. Dual Tower Decoupling Principle

Candidate generation decouples the user representation u = f(x_u) from item representations v_i = g(x_i). Because the item network g is independent of the user, item embeddings can be precomputed offline and indexed in sub-millisecond MIPS / ANN structures (e.g. FAISS, HNSW).

Score(u, i) = ⟨u, v_i⟩ = ∑d=1D ud · vi,d

2. In-Batch Negative Contrastive Loss

Models are trained with cross-entropy loss over in-batch negatives. For a batch of B user-item interaction pairs, positive pair (u_b, i_b) treats all other B-1 items in the batch as negative candidates:

Loss = - (1/B) ∑b=1B log [ exp(⟨ub, vb⟩ / τ) / ∑k=1B exp(⟨ub, vk⟩ / τ) ]

Temperature τ = 0.07 sharpens the distribution, driving gradients into hard negatives.

3. Sub-Millisecond Serving SLA

During live serving, evaluating the user tower takes ~0.15ms, and the dot-product scan / ANN retrieval takes ~0.03ms, achieving a total P95 latency of 0.18ms—far below the enterprise 15ms recommendation SLA.
