Two-Tower Architecture & FAISS Retrieval

Symmetric Contrastive Learning • Zero-Leakage Holdout Verified

1. Dual Tower Decoupling & Cold-Start Metadata Pooling

Both User Tower f(x_u) and Item Tower g(x_i) fuse ID embeddings with genre and multi-hot content tag projections, outputting L2-normalized 32D vectors. New users or new items without interaction IDs are projected cleanly via metadata-only embeddings.

Score(u, i) = ⟨u, v_i⟩ = cosine(f(x_u), g(x_i)) ∈ [-1, 1]

2. Symmetric InfoNCE Contrastive Loss (τ = 0.07)

Trained with AdamW + Cosine Annealing across 977 train pairs (strictly disjoint from holdout test targets), balancing user-to-item and item-to-user softmax cross-entropy over in-batch negatives.

L = 0.5 * [ CE(U·V^T / τ, I) + CE(V·U^T / τ, I) ]

3. Production FAISS Indexing Backends

Pre-normalized Item embeddings are indexed offline into FAISS IndexHNSWFlat (Hierarchical Navigable Small World graph), FAISS IndexIVFFlat (Voronoi cell probing), and FAISS IndexFlatIP (exact MIPS benchmark reference), achieving 98.0% HitRate@10 on unseen holdouts in sub-millisecond latency.
